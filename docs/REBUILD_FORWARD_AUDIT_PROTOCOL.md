# R² 趋势重建：逐事件前瞻基本面审计协议 v1.0（2026-10-20）

**性质**：研究用途。不可自动买卖、替换 OLS Top1、向历史回填发出即时买入提示。本协议用于在真实未来样本上验证“新闻/基本面增量信息”及“不同品种应采用不同审计标准”。

## 0. 研究目标与覆盖透明性

重建信号沿用已冻结 26 日 weighted log-price OLS、半衰期 10（权重 q²），annual 从非正翻正后 1–3 日 R² 改善的 REBUILDING_QUALIFIED。每次检测须显示：

- `market_data_date`、行情来源、最新成份范围 `universe_n`、实际完整扫描 `scanned_n` 和滞后名单。
- 现行 `data/fundamental-audit-trigger.json` 的约十余只研究池 **并非全市场**。历史 1,090 只 ETF 的 2026-09-17 冻结归档也**不能**当作今日的全市场信号。广覆盖持续更新打通前，明确标记 `coverage=limited_pool`。
- 只要已有正式 REBUILDING_QUALIFIED 就应启动审计，不以 Top1 排名筛选；同指数多只 ETF 共用一个底层驱动审计，但各保留独立代码、溢价和成交可行性记录。

## 1. 事件时间线：先做决定，再看结果

以 `event_id = <symbol>:<annual_cross_date>:<first_qualified_date>` 稳定标识；同底层指数聚为 `driver_group_id`，但不能删除逐 ETF 原始事件。

- `T0`：**首次看到合格信号时**记录 `signal_date`（收盘日）、`detected_at`（处理时间，北京时间）、`audit_created_at`、实际市场数据截止、信号数值、适用 driver-map 版本、审计证据的发布时间与首次可得时间，锁定首次 `decision_at_T0`、`confidence`、`entry_feasibility`。如果只是 1–3 日合格后才看到，应忠实标迟到，不能虚构 T0。
- `T+1, T+3, T+5, T+10, T+20, T+40` 或关键基本面改变时，**新增** `follow_up`：新的行情、R²/annual、相关基本面、交易溢价、先前预测状态；**不得覆盖原始 T0 观点**。
- 截止点之后才发布的新闻，不得作为 T0 的证据；后补历史记录必须注明 `retrospective_backfill`，不混入前瞻验证集。
- 没有足够证据填 `UNKNOWN`、`DATA_STALE` 或 `UNVERIFIED`。任何系统性单一驱动映射（例如化工一律看原油）均视为方法错误。

## 2. 两层框架：统一可比字段，资产专属审计

统一字段：`signal_snapshot`（annual/R²/R²增量/动量/波动/是否急拉）、`underlying`（真实指数、权重、地区、成份、期货/现货）、`drivers`（相反证据都保留）、`repricing_vs_persistence`（一次性冲击/持续性变化/混合/未知）、`confidence`（强/中/弱/未知）、`premium_and_fx`、`conclusion`（ALIGN/MIXED/DIVERGE/UNKNOWN）、`entry`（CAN_CONSIDER_ENTRY/WAIT/AVOID_ENTRY/UNVERIFIED）、`evidence`（URL、event/published/first_known_at、访问时点、数据发布周期），`next_check` 与 `falsifiers`。

**资产专属 Driver Map**（必须以基金实际追踪标的为准，映射错误不得下结论）：

| family | 主要指标与因果链 | 主要反例与错配风险 |
| --- | --- | --- |
| 国内化工/能源化工 | 成份期货权重、甲醇/PTA/PX成本差与加工利润、装置开工检修、社会库存、MTO/纺织终端订单、期限结构 | 原油上涨但化工终端弱、装置复产、价格受溢价驱动 |
| 原油/能源 | OPEC+政策、产量、油气库存、全球需求、月差/期限结构、运费、汇率、供需预测修订 | 单次地缘跳涨而供需未变化 |
| 黄金/白银 | 真实利率、美元、央行需求、ETF资金、期货持仓；白银额外看工业需求、库存 | 单日避险溢价回落，白银与黄金驱动不一致 |
| 农业/豆粕 | USDA供需、主产区天气、国内进口到港、压榨利润/开机、养殖饲料需求、季节性、基差 | 一次天气冲击而库存仍充足 |
| 银行 | 净息差、存贷款利率与信贷增长、不良/拨备、房地产/地方债风险、资本充足、分红、政策 | 只用股息率/金融政策利好忽视资产质量 |
| 军工 | 军费预算、订单/合同及交付、行业采购周期、上市公司收入确认、估值 | 地缘突发新闻无订单传导 |
| A股宽基/行业 | 指数权重、盈利预期修订、估值/利率、内外资流向、行业政策、成交结构 | 指数由少数大权重拉动；基本面广度不足 |
| 美国科技/标普消费/生物 | **准确指数成份**、盈利指引/估值、真实利率、行业特定需求/监管与研发、汇率 | 把可选消费当必需消费、把个股涨幅当整个指数 |
| 国家/地区ETF（巴西、印度等） | 当地央行利率、通胀、财政、汇率、成份行业与估值、海外资金、QDII供需 | 受交易溢价主导而非底层资产上涨 |
| QDII/LOF/跨境 | 底层指数本币涨跌、人民币汇率变动、NAV可见日期、场内溢价、申赎限制、流动性和涨跌停 | 高溢价不可交易，或用未来净值回填历史 |
| 债券/转债 | 利率曲线、信用利差、违约风险、转股溢价率、成份权益趋势、债券流动性 | 把信用风险低误当没有利率/转股风险 |

未知资产先核实追踪标的、成份、重心风险，**不能依据 ETF 名字硬套类别**。

## 3. 首次审计需回答的五个问题

1. **为何涨**：观察到的客观价格/基本面变化是什么？哪些只是推测？
2. **为何会继续**：未来 5–20 交易日支持因素有没有继续更新的机制（库存、业绩修订、利率政策实施、持续资金）？
3. **怎样失效**：至少两个具体反证指标与未来观察窗口是什么？
4. **是否已兑现**：底层资产走势、场内溢价、涨幅加速度、估值和成交是否脱节？
5. **当前能够执行吗**：历史净值时点、溢价和流动性能否支持次一交易日下单？无法确定即 WAIT/UNVERIFIED。

新闻没有正向信号不代表不可交易；高可信度的**不利证据**可产生人工 veto 建议，但不自动下单或修改 OLS。

## 4. 持久归档结构

- 优先复用 `public.live_news_audits` 的当日 `payload` 作为原有综合审计摘要，**不覆盖已有新闻和持仓结构**；首次独立事件归档到 Notion 研究记录/每日报告，标明 event_id、原始时间与完整证据。Supabase 如需独立 event-level append-only 表须另行核实安全和权限。
- 独立事件记录应以 append-only 方式保存 `initial` 与不同 `follow_up`，不得以今日判断覆盖过去决定。存储写入后需读回验证并记录失败。
- 仅当产生新合格候选或风险判断发生实质变化时发送 PushPlus；每天日常简讯沿用既有节奏，不新增第二套重复通知。
- 复盘时统计按 driver_group/date 去重后的分组表现、错误类别（驱动误判、执行溢价、趋势假阳性、新闻滞后）、风险预警是否早于价格恶化，以及审计带来的机会成本。
- 在未来样本尚未形成足够独立驱动事件前，不用历史数据优化资产专属规则，避免以结果反向改写审计准则。
