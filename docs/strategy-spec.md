## 2. OLS 选标与 V1 换帅

- 每只风险ETF及511220使用最近26个有效收盘价的加权log-price OLS。
- `LOOKBACK_DAYS=25` 表示取26根价格；`NOMINAL_HALF_LIFE=10`，`np.polyfit`传入q，实际拟合损失权重为q²。
- 年化趋势：`exp(slope * 250) - 1`。
- 正向分数：`annualized * R²`；只有annualized>0且R²>0才产生正分。
- 最近3个交易日任一单日跌幅严格低于-3%，该ETF不合格。
- 风险候选必须严格战胜511220比较器；否则正常目标为空仓。
- V1(75)：新Top1的252日成交额阻力分位达到75%以上，且其raw OLS score单日增量<=0时，若旧仓仍有效则拒绝纯排名换帅；旧仓失效时V1不得阻止退出。

## 3. State Map 与 Void

State Map仅用raw OLS分数，不套用D2或溢价过滤：

- Breadth：14只风险ETF中raw score严格高于511220的比例，固定分母14。
- Leadership Gap：raw Top1与raw Top2分数之差。
- Gap Percentile：相对截至当日最近252个有效交易日的历史分位。
- Breadth<50%且Gap Percentile<50%进入DEFENSIVE_VOID。

Void Route Baseline v1：
1. 首次进入Void，冻结进入前实际策略输出的incumbent，不接受Void当日新换帅。
2. Deepen1：Void内Breadth与Gap Percentile同时低于本次Void进入日水平。
3. incumbent raw score<=511220 raw score，或raw score不可用，视为失效。
4. 仅当Deepen1与incumbent失效同时成立才允许路由：513500上市满365日、raw score>511220且通过溢价检查时路由513500；否则路由511220。
5. 一旦路由，本次Void结束前保持route target；退出Void恢复正常V1。

## 4. M1 + Q90 仓位控制（新增适配器）

### 4.1 风险严重度与概率校准

输入必须是**最终可执行ETF本身**、同一信号日的逐资产预测，不能把raw Top1预测套到被V1保留的旧仓或Void incumbent。

设：
- Q90：未来5交易日，从下一交易日开盘到期间最低价的最大不利变动90%分位数。
- Dnormal：对应正常风险基线。
- P0：原始模型预测未来5日最大不利变动>=5%的概率。
- Pvol：波动率基准模型的同事件概率。
- recent_err：最近最多120个已成熟风险预测的平均误差，定义为实际标签Y−P0；预测标签需成熟且保守滞后10个全球交易日。
- n_recent：可用成熟误差样本数。

M1概率：
`correction = 0`，当n_recent<40；否则
`correction = clip(0.65 * recent_err, -0.12, +0.12)`
`P_M1 = clip(P0 + correction, 0.005, 0.995)`

Q90基础减仓：
`E_Q = clip(1 - 1.10 * Dnormal / Q90, 0, 1)`

概率倍率：
`M = clip(1 + 2 * (P_M1 - Pvol), 0, 1.8)`

最终减仓与目标仓位：
`E = clip(E_Q * M, 0, 1)`
`target_weight = 1 - E`

不额外引入未经回测的5%最小减仓门槛或5个百分点目标变化带宽。0.5%仅作为执行完成度容差，不改变M1理论目标。

### 4.2 每日信号接口

当前策略代码只实现M1计算与安全执行适配器，**没有生产级逐ETF模型预测生成器**。上游信号须在开盘前注入`g.m1_risk_signal`，且至少包含：

- `date`、`data_asof`：必须等于策略信号日；
- `symbol`：必须等于V1、溢价及Void路由后最终可执行ETF；
- `scope`：必须为`per_asset_final_target`；
- `model_version`：非空版本号；
- `q90`、`normal_risk`、`p0`、`p_vol`、`recent_err`、`n_recent`。

任何日期、标的、范围或数值校验失败均视为无效预测。不得使用其他ETF或raw Top1预测替代。

### 4.3 正常市场行为

- 每个信号日重新计算目标仓位，允许同一ETF减仓或补仓，也允许换标的。
- 新标的使用自身同日M1/Q90预测，不沿用旧标的风险值。
- 同一持仓缺少有效预测时，保持现有实际份额，不加不减。
- 新风险目标缺少有效预测时，目标仓位设为0，禁止以100%全仓作为默认值；原有旧仓退出与防御回退仍按执行保护处理。
- 旧的固定5日仓位锁定不再用于M1仓位适配器。

### 4.4 Void行为

- 进入Void且尚未触发防御路由：冻结券商/策略账户中的实际持仓份额及现金；不执行M1减仓，也不因M1回落自动补仓。
- Void时账户为空仓：继续空仓，不自动买入被冻结的策略incumbent。
- Void检测到多个策略持仓：冻结账户现状并停止自动调仓，等待人工核对。
- Void触发原有513500/511220防御路由时，路由优先于M1，沿用现有路由配置。
- Void退出后重新按正常市场逻辑计算最终目标ETF及其同日M1仓位；没有有效预测不得新开风险仓位。

**路由边界待单独确认：** 现有513500路由仍沿用原策略100%目标仓位语义，可能使用Void前由M1保留的现金；本PR没有改变该路由，也没有把它宣称为已通过仓位预算回测。

## 5. 交易执行

- T日收盘冻结OLS/State Map信号，下一交易日开盘前完成溢价净值补处理及最终目标计算。
- 09:31检查跳空、旧仓急跌及买入条件。
- 14:00卖出旧仓或按M1目标部分减仓。
- 14:05重新检查真实持仓、旧仓是否成交、溢价、涨停和日内高点回撤后再买入/补仓。
- 买入保护只阻止新增买入，不反向撤销已经完成的减仓。
- 委托提交不等于成交；旧仓未清时禁止买入新ETF。
- 10%溢价保护继续使用真实未复权收盘价与同日单位净值；超过10%剔除，低于10%连续2个已确认净值日后恢复资格。NAV未确认或滞后不得视为通过。
