冻结策略如何运行

01 · 数据更新

收盘后获取行情

每天使用腾讯后复权日线更新 FixV2、511220、防守 Carrier 513500，以及只用于展示的沪深300基准 510300。Live 页不在浏览器里重新计算策略参数。

02 · 趋势评分

计算冻结 OLS Score

对候选资产使用 26 日加权 log-price OLS，half-life=10。趋势斜率年化后结合 R² 得到 Score，只认可冻结规则定义下的正趋势。

03 · V1 竞争

在 FixV2 内产生候选

使用已冻结的 FixV2 + V1(75) 竞争与过滤逻辑生成常规目标。Live 阶段只执行既有规则，不根据新发生的一两笔交易修改阈值。

04 · 市场状态

读取二维 State Map

Breadth = 13 个风险资产中 Score 高于 511220 的比例；Leadership Gap = Top1 与 Top2 Score 差值的 252 日历史分位。两者共同决定当前四象限状态。

05 · 正常状态

按常规 V1 持有 / 换仓

只要没有进入 DEFENSIVE_VOID，策略继续按冻结的 OLS + V1 规则竞争并执行目标切换。

06 · 首次进入 Void

先冻结原持仓，不立即卖

首次进入防守 / 空窗时，不接受当天新 Top1。冻结进入 Void 前一信号日的真实 incumbent，避免在竞争质量突然下降时追逐短期排名变化。

07 · Void 内观察

等待“双重确认”

暂停普通 Top1 换帅。只有 Breadth 与 Leadership Gap 都继续低于本次 Void 的进入值，才满足 Deepen1；同时原持仓 raw OLS Score 必须 ≤ 511220 Score，才认定 incumbent 已失效。

08 · 防守路由

513500 或 511220

当 Deepen1 + incumbent invalidation 同时成立：若 513500 已上市满 365 日且其 Score > 511220，则路由到 513500；否则进入 511220。Void 退出后恢复常规 V1 竞争。

09 · 成交与记账

次日开盘执行，单边计 6bp

收盘生成信号，下一交易日开盘执行。正式策略净值按开盘 → 下一交易日开盘结算；最新执行日会额外使用收盘价做临时盯市，但临时值不会改写正式净值历史。

Live 页面展示的是冻结模型的前瞻跟踪结果，不是券商真实成交回报。若未来接入实盘成交价，应单独增加“实际账户净值”，而不是覆盖当前模型序列。
