## Question
Holding the asset-exposure structure fixed, are the current ETF/LOF carriers within each exposure actually the best available trading instruments for the frozen OLS Top1 strategy?

## Point-in-time availability
No pre-listing proxy or synthetic history is permitted. A candidate can only influence the strategy after it has enough actual history to generate the frozen 26-session OLS signal.

## Two evaluation views
1. Full-history permanent replacement: replace incumbent from the start of the common backtest. Before the candidate is OLS-ready, that slot is effectively absent. This is the strict historical-realizability view.
2. Matched-availability carrier test: reset both incumbent-base and candidate-replacement paths on the candidate's 26th actual trading session and compare only thereafter. This is the PRIMARY view for answering which carrier should be used today, because late-listed products are not penalized for years when they did not exist.

Both use the same frozen next-open accounting and 6bp/side transaction cost.

## Robust dominance rule (frozen before results)
A candidate is labelled `ROBUST_DOMINATES` its incumbent only if, in matched-availability tests:
- cumulative return delta > 0 in BOTH base A and base B;
- 126-session block wins >= losses in BOTH bases;
- MDD is not worse by more than 2 percentage points in either base.

Among robust dominators, ranking uses the mean matched log-wealth advantage across base A and base B. This is a historical robustness ranking, not proof of future optimality.

## Outputs
- frozen candidate inventory;

- yearly and 126-session breadth;
- slot summary with robust dominance labels;
- explicit separation of strict same-exposure conclusions from same-role sensitivity conclusions.

## Interpretation discipline
Do not call the historical winner 'the true optimal ETF'. A replacement is only a strong candidate if it dominates across both frozen base compositions and multiple time slices. No second-round candidate search after seeing results.
