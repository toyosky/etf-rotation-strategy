# Q5 上涨动态仓位：解释型数学模型与全路径配对回测

**日期：** 2026-11-19  · **状态：** 独立research研究，未修改 `strategy/main.py`、工作流、PushPlus或正式策略。  
**重要：** 下列年化/MDD是 **未通过完整价差、Premium10及14:00成交审计的模型结果，不是实盘或真实可交割的回测收益**。

## 1. 研究目的与模型优先级

假设OLS Top1已经通过D2、V1与Void决定目标资产，Q5**不重新排名、不强制调换目标标的**，只研究上涨质量是否值得降低当前风险资产的资金占比。

基础目标持仓`S_t`属于14只风险ETF时：
- 风险ETF投入比例 `w_t∈[0.45,1]`（可调且不加杠杆）。
- 剩余 `1-w_t` 默认现金；以511220作为防守仓位做敏感性对照。
- `S_t = None`（普通现金）或既有Void route为511220/513500时：Q5不加额外仓位过滤，保留冻结基础状态。
- Q5的新增减仓不会改变日后OLS候选排名、D2、V1、Void状态判别；需要严格区分策略目标target和overlay资金权重。

## 2. 数学模型——Q5 continuous_ols_vol，非根据本次收益拟合出的最优参数

记：
- `Z_t = [ln(C_t)-OLS26拟合终点]/weighted_OLS_RMSE`；它是OLS价格正偏离，**不是早期D2日收益Z-score**。
- `P_t` = RV20（日对数收益20日样本标准差）相对自身**严格过去120个RV20观察值**的分位，0–1。新上市/历史不足时默认不启动减仓。
- `Δβ_t = β_t-β_(t-3)`，`ΔR²_t = R²_t-R²_(t-3)`。
- `clip(x,a,b)=min(b,max(a,x))`。

定义：
```
H_t = clip((Z_t - 1.0)/1.5, 0, 1)
V_t = clip((P_t - 0.5)/0.5, 0, 1)
Q_t = 1.0  if Δβ_t >= 0 and ΔR²_t < 0 else 0.5

w*_t = clip(1 - 0.55 * H_t * (0.40 + 0.60 * V_t) * Q_t, 0.45, 1.00)
```
- 价格未显著高于趋势线时 `H=0`，风险仓位100%。
- 高正偏离越大，且自身波动率分位越高，模型允许减仓越大。
- `β升、R²降`只将强度系数由0.5提高至1，**不当作见顶确定性**。
- 采用从T日收盘计算到T+1模拟执行的信号，禁止T以后信息用于T信号。
- 若当前交易后实际权重距`w*_t`不足5个百分点，且持有证券没有换帅，则保留已有仓位不交易，避免微小频繁调仓。
- 权重幅度0.55、起点1.0/1.5以及5%容忍区间是**可解释先验参数**；Q5未在本次样本中寻找最优值，不能视为统计校准完成。

用于**机制对照**的离散模型：
```
w*_t = 0.50 if Z_t >= 1.5 and Δβ_t >= 0 and ΔR²_t < 0 and P_t >= 0.75
       1.00 otherwise
```
分别比较`Z>=1.5 -> 70%`、`Z>=1.5 & β↑ R²↓ -> 70%`、再叠加`P>=75%`的70%/50%。50%是强度压力测试而非推荐配置。加入独立的平均风险暴露匹配常数权重模型。

## 3. 回放与交易成本

- 已核查研究代码 `strategy/main.py`：14只风险ETF、511220比较器、26日指数加权log-price OLS、D2过去3日任一天<-3%否决、V1过去120日成交额阻力/252历史分位否决正常换帅、Raw Breadth/GAP状态图、Void frozen incumbent与Deepen1失效路由513500/511220。
- 2021-01-04到2026-11-16共 **1421个交易信号日**，取Supabase `public.daily_bars`，下一日开盘构造目标持仓，期间至下下日开盘的持有收益。成本 `0.06% × sum(abs(post_trade_weight - pre_trade_drifted_weight))`，该口径使满仓A→满仓B收2次单边成本；若部分减仓到现金则只按单边卖出权重收费。
- 持仓区间内权重按照市场收益自然漂移；次日新信号重新目标权重，避免无成本每日恒定权重假设。
- 额外费用敏感性：每个交易票至少5元佣金 + 0.01%标价滑点，初始名义资本20,000元，账户随模型净值复利变化。**尚未执行100份交易单位逐笔约束**。
- 防守资金敏感性：动态减出的现金改为买511220，同时按卖风险基金、买511220计两边费用。既有Void路由511220维持不变。
- **基准复现尚不完全一致**：本次研究代码数得非Void换仓198次 vs 先前审计196；全部变化209 vs207；本次6bps CAGR58.25% vs原审计58.94%，MDD -37.64% vs原审计-36.12%；**双方11个缺开盘报价日**。必须审查两次分歧和整个实盘执行层，故使用本次相同1421天路径的配对相对比较，绝不以此证明绝对收益真实。
- 历史可确认的premium阻断仅对2026-09-29做近似；其他历史Premium10状态因Point-in-Time净值资料不足没有完整重演。OHLC价格、LOF溢价、上市与可交易性须再次核验。
- **正式策略不是次日开盘立即卖出**：`strategy/main.py`实际在14:00卖、14:05买；开盘到14:00间急跌时，Q5开盘调仓模型可能高估能避免的损失。因此所有数字只代表策略评价代理，不能提交生产。

## 4. 主要模拟结果（共同研究基准）

| 方案 | 全段模拟年化 | MDD | 触发风险ETF日数 |
|---|---:|---:|---:|
| 100%基准 | 58.25% | -37.64% | 0 |
| `Z>=1.5`减至70% | 60.12% | -37.67% | 51 |
| `Z>=1.5+β↑R²↓`减至70% | 61.50% | -37.64% | 19 |
| `Z>=1.5+β↑R²↓+RV20分位>=75%`减至70% | 60.67% | -37.64% | 14 |
| 相同三项、减至50% | **62.21%** | **-37.64%** | **14** |
| 连续w*（无5%交易带） | 59.81% | -37.46% | 182 |
| 连续w*（5%交易带） | 59.45% | -37.51% | 182个信号日有偏离 |
| 连续w*（5%交易带+单笔最低5元） | 59.28% | -37.51% | 同上 |

**解释**：离散50%看起来收益最好，但触发太稀少，绝大部分年份不参与减仓；尤其2026全年的最终大回撤没有被它拦住。连续模型微弱改善MDD，但差不到0.2个百分点，无法称为有效整体风控。

## 5. 等平均仓位对照与交易成本

- 离散50%模型在风险ETF日的平均目标仓位 **99.468%**（只有14日降至50%）；与其等平均暴露的静态仓位（所有风险ETF日固定99.468%）模拟年化约**57.95%**，MDD约-37.48%。虽然分时减仓产生较高历史年化，但不代表独立可预测Alpha。
- 连续模型平均目标仓位 **99.132%**，匹配静态仓位模型年化约**57.76%**，MDD约**-37.37%**；连续带5%容忍模型年化约**59.45%**，MDD约**-37.51%**。相比常数减仓，对MDD并无明确优势。
- 5%交易带时基准满仓交易票411，离散50%模型约428，连续模型约494；后一模型仍有明显微调成本。
- 以现金作为减仓余款：离散50%约62.21%、连续约59.45%年化；余款改511220：离散约62.00%、连续约59.51%年化。差异很小，不能据此决定资金去向。
- 初始2万元下每笔至少5元的敏感性：离散50%约62.21%、连续约59.28%；仍未考虑份额100份、LOF流动性及真实14:00成交。

## 6. 极端事件归因及诊断

离散50%模型触发的14个标的日中，重大下跌和上涨都存在：
- `2025-12-24`信号目标161226白银LOF，后续`2025-12-25`开盘价3.12、`2025-12-26`开盘价2.52，**open-to-open -19.23%**。在本模型开盘价假设中，半仓单日相比满仓少亏9.62个百分点。这是异常重要的收益来源。
- 同一归因也出现反例：`2024-11-26`/27的159529消费LOF上涨，减仓损失部分上涨收益。
- 如果**仅将上述2025-12-24信号的open-to-open收益中性化（人为设为0）**，不重新选标且不重算因子：
  - 基准年化 **64.36%**
  - 离散50%年化 **65.15%**，仅领先**0.79个百分点**（原领先3.96个百分点）。
  - 连续模型年化 **63.99%**，反而落后基准约0.37个百分点。
  - 这一压力测试是诊断，非真实可投资收益；它揭示**结果严重依赖少数极端价格事件**。
- 统一将所有每日风险资产收益截断于±10%的压力测试（同样不可交易）：基准51.07%，离散50%53.26%，连续52.17%；绝对与相对结果均显著依赖极端分布尾部。
- 分年：离散50%于2021、2023、2025模型收益较好；2022、2024低于基准；**2026没有触发这一规则，风险敞口与基准相同**。模型对真正的全时期最大回撤无效。
- 因基础数据历史复权、基金交易溢价和真实14:00可卖出价格尚未核验，本研究严禁把上述高年化收益视为可靠的预期值。

## 7. 决策与下一研究重点

**Q5结论：尚未通过上线门槛。**
1. “上涨结构失稳”可作为风险观察和影子仓位模型，但现有14个强触发日不足以支持50%或70%固定减仓政策。
2. 一个数学上连续、非过拟合的可解释模型已实现并完成与固定仓位及成本对照，当前未显示稳定而显著的最大回撤改善；不应以高CAGR替代有效性检验。
3. 下一轮先**审计基准两次换仓差异、2025-12-25/26白银LOF溢价与14:00可执行价格**，按分钟数据替代开盘卖出假设，核实2026年最大回撤期间为何模型几乎没有警报。
4. 在价格质量与执行校验后进行重放，并采用独立时间段或未来影子样本，检验预先冻结的模型参数和触发率。不可用这批样本再优化减仓阈值追逐62%年化。
5. 正式策略与生产系统**保持不变**。
