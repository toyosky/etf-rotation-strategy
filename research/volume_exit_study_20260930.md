# Volume-based exit / take-profit event study — 2026-09-30

## Design

- Universe: current FixV2 13 risk assets + 511220 comparator.
- OLS: frozen 26-price weighted log-price OLS, half-life 10, annualization 250.
- Held-day sample: daily raw risk Top1 is production-eligible and score > 511220 score.
- VolumeRatio20 = current turnover amount / mean turnover amount of the strictly prior 20 sessions.
- HighCloseDD = 1 - close/high. This is a daily proxy for intraday high drawdown, not a 14:05 executable minute signal.
- Take-profit subsets additionally require current raw-Top1 episode gain > 0 or >=3%.
- Outcomes: same asset future close-to-close 1/3/5/10d return and excess versus holding 511220.
- Thresholds are a coarse predeclared grid; no in-sample optimum is promoted as a rule.

Sample: 1354 held Top1-days, 2021-01-04 to 2026-09-29.

## Machine conclusion

No coarse candidate passes the cross-era robustness screen. Do not add a volume-based hard exit rule from daily data yet.

## Limitation

Historical minute coverage is insufficient for a full 14:05 high-drawdown backtest. The daily High→Close proxy can establish whether the economic mechanism exists; executable intraday timing must be validated prospectively with minute bars.
