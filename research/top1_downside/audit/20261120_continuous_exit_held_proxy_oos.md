# 连续动态撤出：2026-11-20 首轮实际回测（研究性，未批准部署）

## 核心结论与适用性

已执行实际数据计算（非仅设计或触发任务）：正常100% Top1、风险出现后按条件未来5日潜在回撤的90%分位数与组合预算连续撤出；以 B=1%/2%/3%为**情景而非已选参数**。两层验证：
1. **2025—2026日线研究代理**：固定14只风险标的、511220现金比较器，26日实际平方权重 log OLS（半衰期10）、score=positive annual*R²、近期3日跌3%剔除、次开至再次开收益；**没有**V1换帅阻力、Void状态路由、溢价PIT、09:31及14:05验证。这不是正式Top1历史可执行回测。2021—2024年训练，2025—2026年盲测。只作方向性敏感性检验。
2. **2026-09-15到2026-11-19 41个已结算期间**：仓库 `data/live-forward.json` 的冻结策略 **MODEL baseline** 历史目标及已记录的 `daily_return`。在这些模拟期间追加减仓调整，未重新运行真实订单与PIT premium/14:05。恢复原始基线累计-7.5823%、MDD -15.8531%，与仓库摘要逐值一致。

**当前判断：风险撤出在41期模拟模型上减少亏损及MDD，但分位预测2026失校准，条件特征并未超过波动率单变量；不能声称连续预测模型通过严谨OOS验证，也不能据此部署。**

## 冻结的首轮参数/计算方法

风险特征：截至信号日收盘的当日log收益 r1、过去五日log收益 r5、**不含当日**的先前20/120日样本日对数收益波动 `vol20/vol120`。风险状态门 G = `r1 < -max(0.0075,0.7*vol20)` 或 `r5 < -1.35*vol20 且 r1<0`。以上是演示性预设，**没有通过训练期阈值选择；应在下一轮纯训练折中选择。**

样本风险标签：从次日开盘代理价到未来5日交易最低价，`L=max(0,1-min(low[t+1:t+5])/open[t+1])`；样本五日标签重叠，训练—测试间隔保留约10个交易日；同一个训练集内事件不视作独立交易。

训练期符合代理持仓和 G 的160个观测，学得无条件风险尺度 `K90=quantile_0.90(L/vol20)=3.6347363`。四组按 `shock=-r1/vol20>=1.2` 及 `vol20/vol120>=1.2` 分组：
- mild_stable n67, q90 3.796363
- shock_stable n58, q90 3.691283
- mild_expanding n22, q90 2.354132
- shock_expanding n13, q90 1.919333

为防小组过拟合，`K_cond=K90 + n/(n+70)*(K_group90-K90)`；对照 `K_vol=K90`。输出条件未来损失分位代理 `D90=vol20*K`。
模型连续退出比 `E(t)=G(t) ? clip(1 - B/max(D90,eps),0,1) : 0`；正常风险ETF持仓100%，模型输出 `w=1-E`；现金路由/511220不叠加。没有固定撤出百分比分级。

模拟交易：日线代理用信号 t 决定 t+1 开盘至 t+2 开盘敞口及变动；每次变化每侧 `0.0006*notional` 费用，撤出部分放现金0收益。对 live-forward 模型，保留仓库已经结算的日收益作100%基线，按信号日风险比例缩放当期风险ETF敞口，再扣因连续撤出/恢复新增的绝对权重变动每侧0.0006；仅为overlay近似，不能重估底层路线成交费用与滑点。年度与全期复利以按序真实日期组合日收益计算。

## C. 风险预测OOS审核：目前无法证明条件模型有独立增量

在held proxy的66个2025—2026风险门样本上：
- 波动率单变量：90%预测区间实际覆盖率 **84.85%**，pinball loss **0.0072401**。
- 加入下跌异常/波动扩张四组：覆盖率 **84.85%**，pinball loss **0.0072462**（略差）。
- 2025年：28个样本，覆盖96.43%；2026年：38个样本，覆盖76.32%。分布漂移显著，不能声称风险预算的“90%保护”实际实现。
- 样本内训练仅160个触发状态，小分组最少13个；训练分位样本和测试事件均有5日标签交叠，尚无 block bootstrap/置信区间。
- 条件组中波动扩张的训练分位较小而OOS没有优势，说明简单按历史分组决定撤出不可靠。

## 严格结论及下一步

1. 在冻结基线2026年下跌窗口中，连续退出在模拟条件下表现更好，但**只是41期、单一行情阶段**，不能确认长期盈利优势或风控有效性。
2. 风险分位数模型没有达到校准和新增预测力门槛：当前`conditional`不比`vol-only`可靠，建议**正式策略保持不变**。
3. 下一轮必须：验证完整历史状态与PIT/成交可得性；将当前近似模型更新为真正purged walk-forward，加入OLS价格路径成交市场五组特征、按ETF/行情簇区间与bootstrap；从训练期选择门控和预算；在有独立改善后才做连续撤出和动态复仓的真正组合级OOS回测。
4. 此报告未修改生产策略、实盘仓位、业务任务；仅研究分支归档。完整数据源见 `public.daily_bars`、`data/live-forward.json` 和 `research/top1_downside/PREREGISTRATION.md`。
