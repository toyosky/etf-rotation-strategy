# Unified overheat + decline prediction: first deterministic out-of-sample experiment
Status: numeric experimental configuration registered before this run's model outputs; **research proxy, not executable production backtest**.
- Data: public.daily_bars fixed frozen 14 risky assets + 511220 comparator, as-of 2026-11-19. As-of-t 26-close WLS OLS (nominal half-life 10, effective squared weights), 3-day 3% drop veto, compare score to bond; **omits V1/Void/PIT premium/intraday**.
- Training rows must include all selected-risk Top1 trading days, positive/negative/flat, not down-day only. Train chronological expanding 2018 up to 10 trading days before each test year; test separately 2021..2026. Labels need fully observed next 5 sessions, so truncate 2026 before last 5 dates.
- Loss target max(0,1-min(low[t+1:t+5])/open[t+1]). Evaluate 90th quantile, using ratio loss / trailing-20d daily log vol as regression target; multiply forecast ratio by current vol to recover loss D90.
- Baseline is empirical Q90(loss/vol20) times vol20. ML: same deterministic regularized smoothed pinball-regression optimizer in 5 nested configurations: (1) OLS+vol; (2) +overheat; (3) +decline; (4) +both; (5) +both+volume+cross-ETF market. Continuous features; do not bin Z scores. Fix q=0.90, smoothing=0.2 ratio units, L2=0.04, Adam step=.03, 350 full batch iterations, train-only feature standardization, no test-set tuning, clamp forecast ratio at zero.
- Feature blocks: vol+OLS: logvol20, logvol120, beta/vol20, R2; overheat: normalized 10d/20d gains, positive residualZ, 5d acceleration, normalized beta change; downside: 1/3/5d vol-normalized returns, signed returnZ60, negative residualZ, prior20d high drawdown, short/long vol expansion, R2 delta; volume+market: log current amount / previous20 mean, down-day*volume excess, breadth of risk pool vs cash score, top1-top2 score gap (guard missingness).
- Forecast scored on **all risk-held days**, also positive/negative days separately, with pinball loss, quantile coverage, year sample counts.
- Exit evaluation for this first independent trial is intentionally separated from repurchase optimization: at date t, enter a fixed **5-session** partial cash exposure if forecast D90 exceeds historical normal-vol baseline by 10%; continuous exit E=clip(1-1.10*D_normal/D_model,0,1), else 0. Hold that fractional cash exposure for 5 sessions with no new exit signals, then mechanically restore to the proxy Top1; do not train buyback rules. Model and baseline see identical returns, both charged 6bp per-side net turnover; report opportunity costs and 2026 oil excluded sensitivity. Threshold is a fixed research illustration, not approved risk budget.
- All numerical optimization/forecast values must be reported even if the unified model fails. Coverage in 2026 is high-priority. No production modifications.
