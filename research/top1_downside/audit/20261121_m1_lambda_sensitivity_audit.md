# M1 历史误差校准强度 λ 的独立敏感性审计（2026-11-21）

> 研究专用，不更改正式Void、Q90、复仓参数或实盘执行。
> 参数来源确认：`4177b8bb` 预注册文件在结果产生前冻结了 λ=0.65，但未记录为何选择0.65、也未展示强度参数的训练期估计。

## 1. 证据与公式

- 输入：`research/top1_downside/audit/20261120_market_state_calibration_round1_results.json` 的 `dailyPredictions`，n=1,147（2022-01—2026-11-12风险信号日；2021为暖机），160个5日MAE≥5%事件。
- 上游季度原始样本外概率：`20261120_prob_opportunity_oos_predictions.csv`；校准器具体代码：`../code/market_state_calibration_round1.mjs`。
- 对每个测试行，令成熟误差 `r = recentErr`，历史成熟样本数 `nRecent`。保持原策略所有阈值固定，仅扫 λ：

```js
corr = nRecent < 40 ? 0 : Math.max(-0.12, Math.min(0.12, lambda * recentErr));
p = Math.max(0.005, Math.min(0.995, p0 + corr));
Brier = mean((y - p)**2);
```

- 成熟规则由原始逐时研究提供：必须已有未来5交易日标签，保守再滞后至全球交易日 t−10；最近120个风险信号日，n<40回退原始。敏感性复算不改历史误差定义、不改目标或ETF。
- 复算校验：λ=0.65逐行预测与原研究 `p1` 完全一致（最大绝对误差0）；Brier复算0.10139057780968692，原归档0.10139057780968692。

采用按年分层、年内20风险信号日移动块重抽样（1,400次、固定种子）的配对敏感性：`Brier(0.75)-Brier(0.65)` = -0.00003085，95%块bootstrap区间 **[-0.000664,+0.000328]**，跨零。用40日块700次区间 **[-0.000502,+0.000459]**，仍跨零。比较0.65与M0，`Brier(M0)-Brier(0.65)` = +0.00203352；20日块区间 **[-0.000850,+0.004390]**，亦跨零。区间与原始预注册报告的20日块区间数值略异（抽样种子/次数不同），结论一致。

2022–23对较强修正有利；2024–25原始模型反而更好；2026修正再次有利。这是校准关系非平稳，不是某一常数λ精度不足的问题。

2026Q2（58日、16个事件、实际27.59%）：M0预测均值14.85%、Brier .207614；λ=.65预测13.49%、Brier .218276；λ=1 Brier .224467。历史残差推动校准朝错误方向，在风险变化初期进一步降低风险估计；无法靠增加λ解决。

2026Q3，λ=.65 Brier .184378，M0 .195699；2026Q4截至11/12，λ=.65 .230434，M0 .266180。后期风险校准受益但滞后。

## 5. 判定

1. **参数来源**：0.65在先验研究协议中预设，但未记录依据；不能称“训练优化得到”或“最优校准强度”。
2. **敏感性**：0.5—0.75附近形成较平缓平台；0.75比0.65好极少，配对区间跨零。
3. **机制失效**：2026Q2方向错；放大λ使失效更严重。跨年份符号相反，提示M1可能需要对“何时应信任成熟残差”的门控/状态切换做独立检验，而非继续在同一组历史优化λ。
4. **执行建议**：保留原M1 λ=.65作为冻结研究对照；不因为本次敏感性把它改成.75；不接入正式Void。继续Q13关注风险状态转变时校准响应，Q14单独验证减仓后果，不联合优化复仓。
5. **研究边界**：底层是固定今日ETF宇宙回投、OLS Top1代理而非真实逐日执行持仓；2021—26历史曾被反复看过；5日标签重叠、有时序相关。此次敏感性比较属于**事后稳健性审计**，不是新独立样本验证。
