# 2026Q2 按冻结 M1(λ=0.65) 接回原 Q90-E 的逐次减仓审计

**性质：研究代理历史回放，非正式 FixV2/V1/Void/Q10 可成交回测；未修改生产交易逻辑。** 研究日期：2026-11-22。

## 口径与来源

- 1,419个2021—2026研究代理逐日OLS Top1预测：`20261120_prob_opportunity_oos_predictions.csv`。风险日使用2022—2026已冻结M1的1,147个概率预测：`20261120_market_state_calibration_round1_results.json`。按日期、ETF和原始概率逐行核对：**1,147/1,147匹配**。
- 研究对象为固定14只ETF日线OLS Top1研究代理，不是正式路由后的实际持仓。已知PIT溢价、分钟价格、09:31/14:05成交历史不足。过去研究状态机 Void 自身可能独立决定持仓。不能宣称2026Q2真实卖过这些ETF。
- M1：过去120个已成熟风险日误差均值×0.65，最多±12个百分点修正；滞后10全球交易日；最终概率限于[.005,.995]。**仅校准未来5日MAE≥5%概率，不校准Q90严重程度。**
- `E_Q=clip(1 - 1.10×Dnormal/D90,0,1)`；`E_M1=clip(E_Q×clip(1+2×(P_M1-P_vol),0,1.8),0,1)`。维持原概率调幅，未引入独立概率启动。
- 信号t日收盘、权重作用于下一交易日开盘；对每个启动信号锁定5个持有区间，期间不加减仓，期满重新计算，不存在已优化复仓。资金收益沿用存档`ret`和原始组合模拟的单边0.06%费用；只代表研究代理资金曲线。
- 运行：`node research/top1_downside/code/replay_m1_q2_withdrawals.mjs research/top1_downside/audit/20261120_prob_opportunity_oos_predictions.csv research/top1_downside/audit/20261120_market_state_calibration_round1_results.json`。

## 5个新锁定期的逐笔审计

字段解释：P0=原概率；PM1=M1校准概率；Pvol=ETF自身波动基准概率；D90/Dnormal均为风险幅度。未来L5及R5是信号日所选ETF的**反事实未来5日标签**，而非整个策略因换ETF而实现的回报。仓位以目标敞口表示，忽略成交/份额整数约束。

### 1. 5月6日信号 → 5月7日执行，159509 纳指科技

- D90 **10.59%**；Dnormal **8.35%**；触发门槛1.1×Dnormal=9.19%。
- P0 **34.10%** → PM1 **32.02%**；Pvol **17.22%**。最近成熟残差均值-3.208百分点，校准方向向下。
- 仅Q90 E=13.28%；原概率E=17.76%；**M1 E=17.21%，风险目标82.79%**。相较先前相同ETF100%目标，属于新卖出17.21%总资金权重。
- 固定占位5个交易区间；原定期满5月14日再执行新决策，而5月13日已有下一次新E。
- 事后所选ETF L5=**4.58%**，R5=**-0.76%**，未达到≥5%事件。

### 2. 5月13日信号 → 5月14日执行，159509 纳指科技

- D90 **8.59%**；Dnormal **7.23%**；门槛7.95%。
- P0 **19.72%** → PM1 **17.65%**；Pvol **15.83%**；历史成熟残差为-3.186百分点。
- 仅Q90 E=7.40%；原概率E=7.97%；**M1 E=7.67%，风险目标92.33%**。
- **此日不是再卖出7.67%**：上个持仓周期风险目标82.79%，同ETF新目标92.33%，按冻结策略模型反而是**补回9.54个百分点的资金权重**；仍然属于一个新锁定期的部分减仓目标。
- 事后所选ETF L5=**6.15%**，R5=**-3.08%**，达到≥5%事件。5月21日下一交易执行路由重新调整时，已结束本锁定期。

### 3. 5月21日信号 → 5月22日执行，513100 纳指100

- D90 **4.65%**；Dnormal **4.21%**；门槛4.63%，仅略高于门槛。
- P0 **13.09%** → PM1 **8.59%**；Pvol **9.69%**；成熟误差-6.923百分点。
- 仅Q90 E=0.39%；原概率E=0.41%；**M1 E=0.38%，风险目标99.62%**。
- **该日模型同时从前一ETF切换到513100**；“0.38%”是目标现金比重，不等于卖出此前已持有的513100份额。如此微小的比例在实际ETF整手/交易成本约束下可能不可执行。
- 事后该ETF L5=**0%**，R5=**+4.43%**，此次小幅减仓存在机会成本。
- **最关键的5日锁定副作用**：5月25日，同一ETF候选E突然升到**38.83%**，但既有锁定策略继续保持5月21日的**0.38%**目标，不额外减仓。5月25日信号自身未来L5=**8.33%**。

### 4. 5月29日信号 → 6月1日执行，513100 纳指100

- D90 **6.87%**；Dnormal **5.94%**；门槛6.53%。
- P0 **17.85%** → PM1 **14.11%**；Pvol **12.09%**；成熟误差-5.755百分点。
- 仅Q90 E=4.97%；原概率E=5.54%；**M1 E=5.17%，风险目标94.83%**。相对之前已恢复的同ETF100%目标，本次新减仓5.17%。
- 事后选标的L5=**10.03%**，R5=**-2.99%**，实际发生大于5%的尾部回撤。
- 6月1日模型候选E=**19.86%**，6月2日候选E=**8.89%**，但都在5日锁定期间；实际维持5.17%。6月2日信号自身L5达到**18.31%**，进一步说明模型即便在新日期输出风险，也没有改变已锁定仓位。
- 如果期间原Top1切换ETF，研究资金曲线的风险敞口比例会施加到新的ETF；这不等于一个ETF被锁仓持续持有5日。6月8日执行恢复或下一轮决策。

### 5. 6月26日信号 → 6月29日执行，513290 纳指生物

- D90 **6.36%**；Dnormal **5.21%**；门槛5.73%。
- P0 **18.37%** → PM1 **19.88%**；Pvol **11.35%**；成熟误差+2.326百分点，**此时M1校准方向终于变成提高风险**。
- 仅Q90 E=9.96%；原概率E=11.35%；**M1 E=11.65%，风险目标88.35%**。相对先前同ETF100%目标，新减仓11.65%。
- 事后所选ETF L5=**0.62%**，R5=**+11.11%**；这是明显的上涨机会成本案例。
- 锁定区间跨越Q2至7月，按原规则下个可新决策日为7月3日信号，对应7月6日执行；因此本次资产5日结局会跨季度，Q2季度收益只计到6月30日信号对应的交易区间。

## 额外审计：为什么Q2前段未减仓？

- **4月没有一次启动减仓**。4月7日原油501018的D90=21.84%、正常风险Dnormal=24.65%，门槛是27.11%；PM1预测5%事件概率**53.51%**，但Q90门槛未通过，E仍为0。其后该ETF未来5日L5实际**5.15%**。
- 第二季度整体实际未来5日MAE≥5%事件频率**27.59%**，M0平均概率仅14.85%、M1平均概率更低，仅**13.49%**。M1在风险上升期延续旧的负残差，发生反向校准。
- 已发生5%事件的16个信号日中，9日的Q90－概率映射候选E为0；余下7日有正候选，其中5日处于既有5日锁定，只有**5月13日和5月29日**是真正新启动并同步发生≥5%事件的信号。这里的事件标签高度重叠，不可视作16次独立危机。
- 5月21日极小的新E锁定5日，随后5月25日较强风险信号无法改变仓位，是**执行占位规则而非M1计算公式本身**造成的迟滞；M1同时在整个Q2普遍降低概率，是另一个独立缺陷。

## 判定和限制

1. **M1并未改善本季度的事件启动时机**：Q90门槛同原始概率版，实际新锁定期均为五次；减仓幅度平均8.42%，而原概率版约8.61%。
2. 五次新锁定期并非五笔卖单：5月13日是从82.79%上调到92.33%，净买回9.54%资金权重；5月21日还有跨ETF换标的，不能只按E理解为“卖出某ETF”。
3. 低仓位调整的可执行性与费用、真实交易中的ETF份额整数、公允价/溢价问题未验证。
4. Q90原始预测不是已完成动态分位校准版本；M1只改变概率；本次也未读取、复原Q10正式Void重建/复仓状态机，所以**不等于校准M1+正式Q10的回测**。
5. 数据输入为研究用OHLC/next-open收益代理，未来L5以次日开盘及未来五日全时段低点定义，不能等价于09:31/14:05实际成交后的最大可承受回撤，也缺少PIT溢价以及Void冻结/换标的。资产的L5/R5标签与策略在持有期可能换标的的逐日代理收益不可直接相减。
6. **研究结论**：M1的反应速度与固定5日锁定都会压低及时减仓；不得事后用2026Q2优化λ、5日锁定或Q90阈值再声称独立样本外通过。应保持冻结对照，单独验证校准响应与状态机接入，不上线。
