# Q9修正｜以正式Void为主体的Q90非Void仓位管理整合：接口冲突审计
日期：2026-11-21。研究设计，不修改正式 `strategy/main.py` 或任何实盘工作流。

## 用户澄清后重新确定的主体与优先级
**现行FixV2→V1→Void→Premium/日内执行才是正式策略。Q90只是非Void状态的风险仓位执行层，不改变选标、Freeze、Deepen1、失效与路由决策。** 原Q9直接给部分`DEFENSIVE_VOID`日期施加Q90新减仓信号、遇到Void的Q90不匹配清零并可能立即买回，**不是**用户现在确认的最合适集成定义。Q9收益表不可据此直接视作此修正版的最终收益。

严格流程：
1. 原主策略保持不变，利用原有实际最终目标计算：FixV2 OLS + D2 + V1换帅或保留现仓→`resolve_void_target`→Premium10 veto/实际可执行替代目标。
2. 如果**有效控制状态为非Void**，最终目标属于14只风险ETF，且本目标有同日期独立PIT Q90预测，才按原E预测生成证券目标仓位`wRisk=1−E`，E小于5pp视0，距已执行防御仓位差>=5pp才下单，双向允许；不足一手/佣金成本等执行约束另存。若最终目标普通现金 None，则持现金；此时不因Q90重新买风险资产。若最终目标为511220或513500，无Q90覆盖。
3. **首次入Void**：冻结原正式策略输出的ETF身份，同时**保持入Void之前已成交的实际证券份额与现金**，不强制补买到100%，不再使用当天Q90升降E做调仓。自然价格漂移是被动持有，不进行恒定权重再平衡。Void冻结incumbent期间，不因Q90改变仓位，更不因Q90风险缓解越过Void规则复仓/换资产。若市场Map显示非Void但`exit_blocked_by_premium`导致仍在Void，按**实际g.void_in_void / 有效Void决策**而非Map原始象限继续冻结。
4. **Void失效+深化路由**：原策略优先将证券路由至513500或511220，以当时**实际持仓金额和现金总额**执行目标路由；不允许Q90对新路由减仓，保留Premium10和09:31/14:00/14:05拒单约束。若用户想保留现金底仓/部分配置513500，应另立产品层资产配置假设，当前遵循既有Void全目标。
5. **Void退出**：先由正式策略V1/OLSF最终决定风险ETF，然后只对此**实际可执行目标**重新计算对应独立Q90 E，调整仓位。不能根据入Void前Q90的过期E直接一次性补买，或在退出时绕过溢价、跳空限制。
6. **正常V1 veto**：若原Top1 A被否决继续持旧风险ETF B，则必须获取B的真实Q90预测；不能挪用A的Q90。缺预测严格fallback“不执行额外Q90调仓、按原正式策略决定”，并记缺口。若从Void冻结带出一个已减仓的实际持仓，遇到缺预测，不应立即强制复原100%，须记录并继续既有敞口直到可审计的下一次有效信号；与正常新入场无Q90时默认100%区分。这需要明确持久状态。

## 仓库代码的实际冲突点（main现行版）
- `strategy/main.py:1442` `resolve_void_target`正确维护上层状态，且`g.void_in_void`包括Map退出但Premium被阻断而仍强制冻结的状态；不要重写这个状态机。
- `strategy/main.py:1690` 一类的`g.pending_target`只含**证券代码**，没有目标资金比例及持久Q90执行敞口。入Void冻结也只记录`g.last_output_target`证券名；需增加与真实成交相关的仓位目标/执行权重状态，不能让Q90直接篡改`g.last_output_target`。
- `strategy/main.py:903` `holdings_match_target`只判断“是否仅持目标证券”，**不检查仓位比例**；一个70% ETF/30%现金账户在目标恢复90%或减至50%时会被错误认为“无需交易”，彻底阻断Q90双向调仓。
- `strategy/main.py:1870+` `execute_sells_at_1400`仅卖出**不是目标证券**的持仓，不会因相同证券目标E上升而减部分ETF；未实现目标金额止盈/风险减仓。
- `strategy/main.py:1920+` `execute_buy_at_1405`调用`order_target_value(target, context.portfolio.total_value)`，只支持一键**满仓**，会覆盖Q90目标权重；必须改为目标可投资金额并严格保留实际剩余现金。
- `strategy/main.py:1800+` 执行门槛包括09:31跳空，14:00卖出、14:05分钟高点回撤、涨停/停牌、Premium10。Q90是收盘可用风险预测；不能用次日开盘卖出的旧研究代理当成14:00/14:05真实可执行收益。
- 不可因Q90信号进入/离开，把Void原有`void_incumbent`、`void_routed`、`void_route_target`清零；若无部分成交/拒单真实仓位数据，Q90目标不应被当成已经执行完毕。
