# Oracle 提前入场上界实验

日期：2026-09-08
状态：第一阶段完成（理论上界，不是可交易策略）

## 研究问题

在不改变当前 OLS/Top1 定义的前提下，如果事后已经知道“哪只资产将在未来成为新的 Top1”，把它提前 N 个交易日买入，理论上最多能拿回多少收益？

本实验只回答“是否存在值得争夺的提前入场空间”，不回答“当时能否预测出来”。

## 数据与冻结口径

- Supabase `daily_scores` + `daily_bars`
- score 版本：`C0@20260906T_preregistered_primary_v1`
- 日线：GM 后复权 `gm_hfq`
- score 样本：2021-01-04 至 2026-08-05
- 固定 15 标的池
- 聚焦此前问题资产：新 Top1 不含 `161226` 白银、`501018` 原油、`511220` 现金信号
- Top1 episode：`daily_scores.rank = 1` 的 symbol 发生变化时定义一个新段
- 当前 Oracle 原始 episode 数：2021–2024 为 110 段；2025–2026 为 73 段

注：此前 `regime_shift_noncommodity_20210908.md` 的未来收益诊断样本为 110/71 段；本实验直接从完整 `daily_scores` rank-change 序列构造，因此后段样本数略有差异。Pre20 数量级仍一致（本实验 next-open 口径约 8.19% / 8.46%，此前诊断约 8.48% / 8.52%）。

## Oracle 定义

### 1. 毛上界（Gross catch-up）

假设未来新 Top1 已知，实际 Top1 段开始于信号日 T，原策略在 T+1 开盘进入。

提前 N 日 Oracle 在 T+1-N 的开盘就持有同一未来 Top1，并一直持有到原策略正式进入时点。

毛提前收益：

`future_top1_open(T+1) / future_top1_open(T+1-N) - 1`

它只回答“这只未来 Top1 在正式入场前 N 日已经涨了多少”。

### 2. 净上界（Net Oracle gain）

提前买未来 Top1 必然意味着放弃原策略在这 N 天真实持有的 Top1 路径，因此更合理的上界是：

`Oracle 未来Top1在提前窗口的收益 / 原Top1路径在同一窗口的收益 - 1`

这是单持仓框架下更接近真实可增加收益的理论上限。忽略交易成本；若提前窗口内原策略发生多次换帅，则 Oracle 相当于提前锁定未来最终 Top1，并跳过这些中间换帅。

## 稳健性：只看“非白银/原油/现金 -> 非白银/原油/现金”的换帅

为了防止净增益由从白银、原油或现金切回风险资产的少数事件驱动，再限制旧 Top1 也必须属于普通风险资产。

- 2021–2024：1日净 Oracle 平均 +0.97%，中位 +0.69%，胜率 58.2%（79 次）
- 2025–2026：1日净 Oracle 平均 **+1.54%**，中位 **+1.20%**，胜率 **75.9%**（58 次）
- 2025–2026：2日净 Oracle 平均 **+3.20%**，中位 +2.42%，胜率 91.4%

因此 2025–2026 的上界并不是由白银/原油切换事件制造出来的；普通资产之间的领导权更替本身就存在很大的提前切换价值。

## 核心结论

1. **“哪怕提前拿回 0.5% 是否值得研究？”答案是肯定的。**
   - 2025–2026 完美提前 1 日的净上界约 +0.77%/次；中位 +1.06%。
   - 0.5% 并没有超过理论空间。

2. 2025–2026 的关键并不只是“新 Top1 在正式入场前继续上涨”。
   - 新 Top1 在最后 1 日平均只涨约 +0.30%。
   - 原 Top1 同一日平均约 -0.39%。
   - 两者合起来形成约 +0.77% 的净切换上界。
   - 即：**提前收益同时来自更早买新领导者 + 更早离开旧领导者。**

3. 两时期 1 日净上界都很大：2021–2024 约 +0.85%，2025–2026 约 +0.77%。
   - 因此“提前一两天是否有经济意义”不是 2025–2026 才出现的新现象。
   - 2025–2026 更明显的问题在于领导持续时间缩短，使这部分未捕获收益对最终段收益占比更高。

4. 这仍然只是 Oracle。
   - 新 Top1 的出现本身由近期相对表现推动，因此 rank crossing 前 1–2 日存在明显相对强势在统计上并不奇怪。
   - 本结果不能证明当时可以预测，只证明：**可预测性如果存在，即使只捕获 Oracle 的一小部分，也具有足够经济价值。**

## 下一阶段建议

不再继续修改 score 本身，而直接做“可预测性边界”测试：

- 在每次新 Top1 正式出现前 t-1 / t-2 / t-3，记录候选者当时的 rank、score gap、Δscore、Δgap、过去1/2/3日相对收益等；
- 标签：未来 1/2/3 日是否成为 Top1；
- 与所有未成为 Top1 的 Rank2/Rank3 候选作对照；
- 先做单变量分箱和排序，不上复杂机器学习；
- 最终评价不是分类准确率本身，而是：在误报成本计入后能实际捕获 Oracle 上界的百分之多少。
