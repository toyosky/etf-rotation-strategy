# Cluster90 × Resistance + ScoreDelta V1

日期：2026-09-09  
状态：**已完成**

## 研究问题

检验此前固定池中表现较好的 V1 换帅确认机制，能否抑制 Cluster90 的短暂/提前 Top1：

`ResistancePct252 >= 75% AND ScoreDelta_new <= 0 -> veto new Top1`

这里的成交额不是绝对流动性门槛，而是历史成交额在当前价格上方区域的 Volume Profile 阻力。

## 冻结 V1 定义

对新 Top1 候选 B：

1. 使用候选当日收盘价 P；
2. 回看此前最多120个交易日，把每个历史日的 amount 均匀分布在该日 `[low, high]`；
3. `UpperShare = Amount[P,1.05P] / Amount[0.95P,1.05P]`；
4. `ResistancePct252` = 当前 UpperShare 相对于该 ETF 此前最多252个日度 UpperShare 观测的 point-in-time 百分位；至少60个历史 profile 观测；
5. `ScoreDelta_new = Score_t - Score_{t-1}`；
6. 仅当 `ResistancePct252 >= 75% AND ScoreDelta_new <= 0` 时 veto；否则按 raw OLS Top1 换帅。

不搜索 70/80 阈值，不搜索 ScoreDelta 数值阈值。

## Cluster90 适配

- Universe：每月冻结 Cluster90（120日相关性 >=0.90 去重，流动性优先代表）。
- OLS：冻结 26-price / nominal HL10 / exact score / D2 trend_eligible。
- V1 **仅作用于纯排名换帅**：旧持仓仍是当日 Cluster90 的 `trend_eligible` 候选时，才允许 veto 新 Top1。
- 若旧持仓已失去 trend eligibility、当日无候选、或因 Cluster90 月度代表变化不再属于当日候选，则不允许 V1 延长持有，按基线切换/退出。
- 这是为了只测试“提前换帅”机制，不让 V1 覆盖风险/Universe 硬失效。

## 执行与样本

- 数据：ETF_daily_bars Supabase `public.daily_bars`。
- close(t) 产生目标，open(t+1) 执行，open(t+2) 标记日收益；每买/卖一边成本6bp。
- 主样本：2021-01-01~2024-12-31。
- 后验：2025-01-01~2026-09-08。
- 不加 C2/Premium/minute execution。

## V1 是否抑制了 Cluster90 的短 Top1？

**几乎没有。**

- 2021–2024：231 -> 229 次换帅；平均连续持有 4.18 -> 4.21 日；
- 2025–2026：124 -> 123 次；平均连续持有 3.26 -> 3.29 日。

实际 V1 veto 日：

- 2021–2024：3天；
- 2025–2026：3天。

因此 Cluster90 的大量短 leadership 并不是由“高上方阻力 + 新 Top1 Score 已不再增强”这一小类换帅造成的。

## 独立分歧区段

重复 veto 日合并为实际持仓路径不同的连续区段后：

### 2021–2024

共 2 个区段：

1. 2022-05-30~05-31：raw 切入 515790，V1 留在 515220。
   - raw 区段收益约 +2.49%；
   - V1 旧仓约 -1.92%；
   - V1 相对贡献约 **-4.40pp**。
2. 2024-06-26：raw 切入 159941，V1 留在 513310。
   - raw 约 -0.18%；
   - V1 约 +0.75%；
   - V1 相对贡献约 **+0.93pp**。

合计 2 个区段，V1 仅 1/2 跑赢；平均每段相对约 **-1.73pp**。

### 2025–2026

共 2 个区段，V1 两次都跑输：

1. 2025-04-29~04-30：raw 黄金 518880 vs V1 继续印度 164824，V1 相对约 **-0.20pp**；
2. 2026-05-25：raw 切入 513310 单日约 +5.86%，V1 留在 159667 约 -0.29%，V1 相对约 **-6.15pp**。

平均每段相对约 **-3.17pp**。

## 与固定15池 V1 的区别

此前固定15池的相同 V1 只有7个独立分歧区段，其中6/7相对贡献为正，因此它作为固定池候选机制看起来较干净。

但在 Cluster90 中，候选集合和换帅事件完全改变：V1 触发到的是另一批 ETF / 另一批 leadership 事件。结果只有4个独立分歧区段，其中只有1个有利。

这说明：

`Resistance + ScoreDelta` 并不是一个对所有 Universe 都稳定有效的通用“假换帅识别器”。它在固定15池中的成功高度依赖于该池实际出现的换帅事件结构。

## 判定

1. **拒绝把固定池 V1 直接移植到 Cluster90。**
2. 它既没有实质延长 Cluster90 leadership，也没有改善 2021–2024 或 2025–2026 收益。
3. 不调整 75% 或 ScoreDelta<=0，不做二次阈值搜索。
4. 这不否定 V1 在固定15池的候选价值；它只说明 V1 不是 Cluster90 短 Top1 的根治方案。

## 研究含义

Cluster90 的短 leadership 更像是大候选集下普遍的相对排名竞争，而不是少数“上方阻力重、Score 已衰减”的提前触发。

因此，如果目标是把 OLS 扩展到全市场，更合理的方向仍是**前端选标 / opportunity selection**，先缩小到具有可交易趋势结构的高质量候选，再交给 OLS 排名；不能指望固定池 V1 在后端把几十个候选的极值竞争全部修复。
