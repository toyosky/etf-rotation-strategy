# 趋势连续性筛选实验

日期：2026-09-08
状态：已完成

## 研究问题

同一资产（如创业板 159915）在 2025–2026 仍可能长期上涨，但短期价格路径更锯齿、更均值回归。若这一变化不是所有资产共有，而只有部分资产发生，则可以考虑：OLS 负责判断“趋势强不强”，另一个趋势连续性状态负责判断“这种趋势是否适合 Top1 单持有”。

## 固定数据与样本

- 数据：Supabase `daily_bars`（gm_hfq）与冻结 `daily_scores`。
- 主样本：2021-01-04 至 2024-12-31。
- 后验样本：2025-01-02 至 2026-08-05。
- 资产池使用冻结原始风险资产，不含现金 511220。

## 第一层：资产级描述性对照

对每个资产、每个时期分别统计日收益一阶自相关、连续同号比例、波动、强涨/强跌后的次日表现与 5 日动量延续。

### 主要现象

创业板并非孤例。2025–2026 相比 2021–2024，多个资产的一阶自相关明显下降：

- 159915 创业板：+0.078 -> -0.118；
- 159529 标普消费：+0.155 -> -0.079；
- 159825 农业：+0.100 -> -0.079；
- 159981 能源化工：+0.014 -> -0.103；
- 159985 豆粕：+0.009 -> -0.092；
- 164824 印度：+0.056 -> -0.181；
- 511380 转债：+0.072 -> -0.047；
- 513100 纳指：-0.079 -> -0.117；
- 513290 纳指生物：-0.084 -> -0.169。

但不是所有资产都如此。2025–2026：

- 白银 161226：lag1 corr 从 +0.014 升到 +0.198；强涨日后的次日均收益约 +0.834%，强跌日后约 -0.495%；
- 原油 501018：lag1 corr 约持平（-0.010 -> -0.009），但强涨/强跌后的次日收益差从 -0.165pct 变为 +0.393pct，表现出更强的趋势延续；
- 黄金 518880：lag1 corr 近似不变，但强涨/强跌后的次日收益差从 -0.062pct 改善到 +0.172pct；
- 513920 的短期反转也有所减弱。

因此，“2025–2026 所有资产统一变成均值回归”不成立。更准确的说法是：**市场出现明显的资产级路径分化**，部分资产更锯齿/均值回归，少数商品资产则进入强趋势连续状态。

同时，纳指科技、纳指、生物医药等在 2021–2024 本来就存在负的一阶自相关，因此不能事后看到白银/原油的正连续性后，直接把“正自相关”定义成好资产。

## 第二层：可交易滚动状态测试

### 预注册定义

每个交易日仅使用当时及之前数据：

- PRIMARY：过去 60 个有效日收益的一阶自相关 `rho60`；
- SENSITIVITY：过去 120 个有效日收益的一阶自相关 `rho120`；
- 阈值固定为 0，不优化。

只在冻结 OLS 历史表 `eligible=true` 的资产日上比较未来收益。

### 所有 eligible 资产日

2021–2024：

方向发生反转：2021–2024 rho>0 更差，2025–2026 rho>0 更好。

#### rho120

2025–2026：
- rho<=0：未来10日 +0.851%；

## 第四层：白银/原油贡献检查

2025–2026 中，rho>0 的强结果明显集中于超级趋势资产：

- 原油 501018：rho60>0 的 Rank1 日未来10日约 +14.58%；
- 白银 161226：rho60>0 的 Rank1 日未来10日约 +14.24%；
- rho120>0 时，原油约 +9.46%，白银约 +24.20%。

剔除白银和原油后：

### rho60 Rank1

2021–2024：
- rho<=0：未来10日 +1.563%；
- rho>0：+0.724%。

2025–2026：
- rho<=0：未来10日 +1.814%；
- rho>0：**-0.060%**。

因此 60 日正自相关在非白银/原油池里甚至没有后验优势。

### rho120 Rank1

2021–2024：
- rho<=0：未来10日 +1.315%；
- rho>0：+1.152%。

2025–2026：
- rho<=0：+1.169%；
- rho>0：+2.540%。

120 日结果仍存在时期依赖，不能视为稳健过滤器。

## 判定

**拒绝把“滚动自相关 > 0”直接加入正式策略。**

原因：

1. 创业板的均值回归化不是孤例，但也不是全市场统一现象；
2. 白银/原油/黄金在 2025–2026 反而具有更强趋势连续性，说明资产级状态分化是真实的；
3. 但“正自相关”作为可交易筛选条件在 2021–2024 与 2025–2026 方向反转；
4. 后验期的巨大优势主要受白银/原油超级趋势放大；
5. 部分历史上有效的资产本来就有负短期自相关，因此简单过滤会错杀有效趋势。

## 当前研究含义

“寻找满足条件的标的”这个更高层思路仍然值得保留，但条件不能简单定义为原始日收益正自相关。

更合理的下一步是寻找与现有 OLS 模型更一致的 **趋势可交易性 / leader persistence** 状态，例如：

- score / rank 在过去若干日的稳定性；
- Top3/eligible 持续时间；
- slope 与 R² 是否同时稳定而非仅瞬时高；
- 强趋势资产之间的横截面领导集中度。

这些指标直接描述“当前强趋势是否能维持领导地位”，比单纯的一阶自相关更接近本项目最初发现的问题。

本实验不继续优化自相关窗口和阈值。
